# 🏏 IPL Sports Analytics Dashboard (2008–2024)

## 📌 Overview
End-to-end data analytics project on 1,095 IPL matches 
across 17 seasons — covering EDA, visualization, and 
machine learning.

## 🎯 Key Findings
- V. Kohli — All-time top scorer: 8,014 runs
- Y. Chahal — Top wicket taker: 205 wickets
- 64.3% teams chose to field after winning toss
- Random Forest model: 72%+ match prediction accuracy

## 🛠️ Tools Used
Python | Pandas | Seaborn | Scikit-learn | Power BI | Excel

## 📊 Project Structure
- notebooks/ — Python EDA + ML code
- dashboard/ — Interactive HTML dashboard
- report/    — Excel KPI report
